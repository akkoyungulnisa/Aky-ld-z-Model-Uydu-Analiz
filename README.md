# Aky-ld-z-Model-Uydu-Analiz
STM32F103C8T6 tabanlı, 1710g kütle hedefli model uydu simülasyonu. Python ile geliştirilen sistem; aerodinamik iniş dinamiği (9.64 m/s), SX1278 LoRa link bütçesi ve enerji akış analizlerini (Sankey/Heatmap) gerçekleştirir. Niğde Ömer Halisdemir Üniversitesi Ar-Ge çalışmaları kapsamında üretilmiştir.
